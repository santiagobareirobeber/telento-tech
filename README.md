# Cine Aniplex - Página Web Oficial

Este proyecto consiste en el desarrollo de la página web para **Cine Aniplex**, un sitio diseñado para mostrar productos/servicios cinematográficos, reseñas de clientes y permitir el contacto directo mediante un formulario funcional.

## Propósito del Proyecto
Proporcionar una interfaz web accesible, moderna y responsiva que permita a los usuarios:
1. Navegar fluidamente entre las diferentes secciones del sitio.
2. Consultar las entradas y combos disponibles en la sección de Productos.
3. Leer opiniones de otros usuarios en la sección de Reseñas.
4. Enviar consultas directamente al equipo de atención a través de un formulario de contacto y visualizar la ubicación del cine.

## Tecnologías Utilizadas
- **HTML5**: Estructura semántica completa (`header`, `nav`, `main`, `section`, `footer`).
- **CSS3**: Estilos personalizados, tipografía desde Google Fonts (Poppins), fondos con gradiente e imágenes.
- **Flexbox**: Utilizado para la organización responsiva de las cards de la sección "Productos".
- **CSS Grid**: Utilizado para la distribución adaptativa de la sección "Reseñas".
- **Media Queries**: Utilizadas en la sección "Contacto" para adaptar el diseño de pantallas móviles a de escritorio.
- **Formspree**: Integración para el procesamiento del formulario de contacto.
